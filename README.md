## Lab 6 — настройки, хранение, резервное копирование

### Функциональность

- **Экран настроек** — переход с Home по кнопке «Настройки», возврат по «На главную».
- **Хранение настроек**: DataStore (email/никнейм, уведомления, тёмная тема), SharedPreferences (имя файла резервной копии).
- **Экспорт** — список персонажей с Home сохраняется в .txt во внешнее хранилище (Documents / Downloads). Имя файла по умолчанию: `characters_23.txt`.
- **Резервная копия** — при удалении внешнего файла создаётся копия во внутреннем хранилище приложения; файл можно восстановить из резервной копии.
- **Права** — для работы с внешним хранилищем запрашиваются `READ_EXTERNAL_STORAGE` и `WRITE_EXTERNAL_STORAGE` (Android 8).

### Зависимости

- **DataStore** — `androidx.datastore:datastore-preferences`

### Структура (новые/затронутые части)

- `ui/settings/` — SettingsFragment, SettingsScreen (Compose), SettingsViewModel, SettingsRepository
- `storage/` — PreferencesDataStoreManager, SharedPrefsManager, BackupFileManager, CharacterListCache

---

Заметка: если удалить внешний файл, а после переименовать его, то восстановить его из резервной копии невозможно в связи с тем, что название резервного файла и внешнего не совпадают. Если написать имя, которое было до удаления (то бишь файл сохранен в резервную копию), то ошибки не возникает.
